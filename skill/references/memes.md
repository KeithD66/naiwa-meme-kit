# 热梗库（2026 中文互联网抽象梗）

> 用于给奶蛙短视频选题材、配台词、找 BGM。来源：ACGO 题库《2026年度每月奇葩热梗TOP3》、游民星空、腾讯新闻、原仓数据等。
> 用法：每条含「来源 / 玩法 / 适配场景」，创作时按需取用。

## 奶蛙本体梗
- **大笑 / 齁齁齁**：奶蛙招牌。罐头笑声式，关键节点大笑收尾。配"哟齁齁齁"私人笑声。
- **秒开战斗脸**：学《无畏契约》选手康康，奶蛙突然收起嘻皮变严肃。反差梗。
- **不知火舞语音**：变调版不知火舞语音 + 奶蛙形象，黄色创作浪潮的固定搭配。
- **豆奶 CP**：奶蛙 × 豆包 组 CP。
- **奶家人**：粉丝自称，"举旗"表情（参考图中有"奶家人"旗）。

## 雷霆 / 舞蹈流派（用户目标"奶蛙雷霆视频"所指）
- **唐佳琪舞蹈**：博主唐佳琪开创。雷霆表情 + 雷霆舞步 + 双闪屁股灯 + 牛仔帽，配小曲《Monica / jim okimia》，苛刻变焦 + 张力表情 + 剪辑，"颓须、六亲不认的步伐"。已成可模仿的视频流派模板。
- **大狗大狗**：魔性循环 BGM，类哈基米，剪辑万能配乐。
- **来杯好茶摇一摇**：星穹铁道×茶百道联动曲，万能转场 BGM。

## 万物皆可"X 来"（牛来衍生）
- 狗来 / 马来 / 猪来 / 金来 / 盔来 … 凑十二生肖，品牌官号跟风模板。
- **绊倒体 = 半导体**：牛来被石头绊倒名场面，炒股被套梗。
- **妈妈，牛来！**：魔性配音口头禅。

## 反应素材（万能）
- **AI 黑猫拍手**（2026.10）：长人手黑猫缓慢拍手绿幕素材，看到离谱内容时用。
- **夯爆了 2.0**：夸高质量作品。
- **肥嘟嘟**："你的胆子真是肥嘟嘟的"，配美团袋鼠，吐槽胆大离谱。

## 其他常驻
- **大智斗时代 / 五代石国**：熊出没考古，把剧情解读成步步算计，用于"过度解读"整活。
- **柯洁惊鸿一瞥**：名场面表情包。
- **扣肉娘娘**、**同款头绳经济学**：生活向热梗。
- **野生狗奶**："生命畏惧时间，时间畏惧野生狗奶"，评论区玄学整活。

## 使用方法
1. 选一个奶蛙"人设动作"（大笑 / 战斗脸 / 雷霆舞步）。
2. 套一个当月热梗做题材或 BGM。
3. 结尾固定"大笑收尾"或"反差转折"，符合奶蛙视频范式。
