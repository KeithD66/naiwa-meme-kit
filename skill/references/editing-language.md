# 雷霆视频的声画编排

目标是“辨认得出同一只网传奶蛙，熟悉原声一响就有梗”。不要把“雷霆”翻译成更换角色、无限噪声或不停变焦。

## 先选素材，再分配刺激

用 `library/recipes.json` 选节奏结构，再用 `library/audio-cues.json` 和 `library/catalog.json` 填入具体资产ID。配方是剪辑意图，不是视频模型能凭空拿到素材的指令。每镜头的文件、动作参照、音频入出点和审核状态都要写进 brief。

- **识别段**：给闭嘴脸、全身、原声留辨认时间。字幕短，先交代一个小目标。
- **触发段**：用一条熟悉口癖或一次凝视引发变化；不要堆三条人声。
- **升级段**：全身舞步保证能看见脚；脸部强变焦是短插镜，不是整段把脚裁掉。
- **断点**：半拍安静、突然定格、硬切小景别，给下一次声音让位。
- **回报段**：连续捧腹大笑与已选原声同时落下；末尾可回扣开头。

这些时间建议可按实际音源变化，不硬凑20秒，也不让模型“按想象唱一段”。舞步须来自已取得的参考片段；普通桌宠走路帧不能被命名成“原版雷霆舞步”。

## 可组合手法

| 手法 | 用途 | 素材边界 |
|---|---|---|
| 100%→170%→110%短促变焦 | 重拍、战斗脸、突然接话 | 剪辑改变景别，不改眼睛形状/嘴/体型 |
| 同源动作重复两遍 | 第二遍的提前/延后落点制造预期 | 不增添新肢体动作冒充原片 |
| 定格＋断乐＋一句短字幕 | 给观众半拍反应，再接反转 | 字幕由剪辑层排版，避免模型烘焙乱码 |
| 口癖接力 | 配角出场身份识别 | 一个角色一套视觉与声音，不随机互换 |
| 原片笑声后置 | 先憋住，再破功 | 必须选现成文件，试听和时间点写清楚 |
| 尾帧回首帧 | 循环播放 | 先在剪辑中验证声音和构图能接回 |

## 声音轨道

声音按功能分轨：角色原声／BGM／现成转场音效／短暂静音。人声优先；人声出现时可让BGM降低约4–8 dB，再按实际试听调整。保留动态，峰值不削波，不用“越响越炸裂”掩盖不合拍。不要把不同来源录音先批量变速、变调后丢掉原文件；衍生版必须另记源ID、处理参数和许可。

`audio-cues.json` 没有候选文件的cue就是缺口。可换成已有口癖、调整动作或安静停顿；不能自动使用实时合成笑声、TTS仿声或从商业App解包填空。

## 逐镜头验收

1. 无声看一遍：仍是同一只奶蛙，眼睛、嘴、腹斑、手脚没有变成奶龙或通用青蛙。
2. 只听声音：能分清谁在说话，BGM不盖住角色识别声，没有错误截断。
3. 合起来看：落脚、变焦、口癖起音和笑点在同一节奏；静音是真留白。
4. 首尾连看两遍：循环不会突然多出一句话或换角色。

身份漂移时先缩短动作、减小转角、保留原片或增加现成参考；不靠一长串形容词把“新奶蛙”美化成“已锁定”。
