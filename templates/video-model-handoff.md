# 视频模型交接规则

这里的“奶蛙”指本项目提供的网传版现成角色，不能按名字或一段外貌描述重新设计。先读取本地 `brief.json`，查看其中每一个参考文件，确认工具实际收到附件；本地路径和URL文字不等于图片已上传。

## 给图生视频模型的动作指令

以已上传的主参考保持唯一角色身份。保留参考中的头身比例、灰绿圆眼黑瞳、一字嘴、乳白腹斑、手脚颜色与结构。其它附件只提供同一角色的表情、动作或视角，不能把素材中的配角特征融合到奶蛙上。

只执行本镜头 brief 指定的动作和相机运动。先固定机位、短时长、小幅动作；没有对应参考就不做大角度背转。战斗脸用停顿、收笑、凝视表现，不将眼睛改成锐角眉眼。动作失败时缩小动作、缩短时长或换现成片段，不重新设计角色。字幕、贴纸和音频留给后期。

配角须有独立附件与自己的角色ID。在工具支持独立角色引用时逐角色绑定；不支持时先分镜单独生成再剪辑，不能只在同一个文本prompt写一串名字。

## 给剪辑模型的声音指令

从 brief 的 `audio_assets` 读取真实录音。先试听匹配cue，填写 `source_asset_id / in_seconds / out_seconds / playback_rate / audition_result`；不要给角色合成“差不多的笑声”，不要自动换BGM版本。没有合适音源时报告缺口，并用安静或已有可用cue改脚本。

## 启动条件

只要 `blockers` 非空或 `generation_allowed` 为 false，本文件就是策划交接草案。先按项目工作流处理具体缺口和用户当前授权，不能自行将 false 改 true 当作取得授权。对外分发还要逐条核对媒体许可。
